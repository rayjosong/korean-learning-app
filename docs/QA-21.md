# QA: Backlog #21 Progress dashboard

## Canonical surface

- Direct route: `/progress`
- Entry point: primary Home navigation
- Persistence: local browser IndexedDB only
- Design intent: recent review recall is the primary learning evidence; state counts and activity support it.

## Acceptance evidence

| Criterion | Evidence |
| --- | --- |
| Known items | Domain aggregation and populated route assertions cover current `known` items. |
| Learning items | Domain aggregation and populated route assertions cover current `learning` items. |
| Review success | The domain uses an inclusive rolling 30-day window, omits future and invalid timestamps, shows the successful/total denominator, and renders a no-recent-review state instead of 0%. |
| Explanation frequency | The domain preserves the inclusive seven-day activity window. |
| Content studied | The domain trims IDs and deduplicates studied content. |
| Comprehension-first hierarchy | The page leads with Review recall. Learner state and activity sit in secondary sections; no streaks, XP, score, ranking, or total-comprehension claim is present. |
| DESIGN.md layout | The canonical desktop route uses the existing warm editorial tokens, whitespace, hairlines, restrained metric treatment, and active navigation semantics. |
