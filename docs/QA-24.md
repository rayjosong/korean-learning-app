# QA-24 - Opinionated recommendation engine

## Scope

Backlog #24 adds one deterministic, local-only recommendation to Home. The recommendation uses due learning items, recent review outcomes, resumable content, and replayable content-progress snapshots. It never calls an AI provider or external content service.

## Evidence

- Domain policy tests cover fixed priority, recent recognition/production failure reasoning, deterministic ordering, eligibility boundaries, fingerprints, and dismissal expiry.
- Storage tests cover coherent input reads, dismissal round-trips, and version 10 -> 11 migration preservation for learner data and AI provider settings.
- Home tests cover structured reason copy and the existing Home model; component and browser fixtures cover recommendation placement and dismissal.
- The Home fixture clock remains pinned to 2026-01-15 for deterministic browser runs.
