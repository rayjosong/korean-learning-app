## Result

Complete. The existing #29 visual baselines remain in place, and the #32 suite adds deterministic coverage for the implemented Home, Watch, Study, Review, Progress, Settings, utilities, responsive, feedback, loading, and error states.

The implementation also pins the existing Pretendard typeface locally, fixes the expanded popover heading hierarchy, and adds a visible `▶` cue for the currently playing transcript row so playback and selection remain distinct without relying on colour alone.

## Determinism

- Browser date is fixed to `2026-01-15` in the fixture harness.
- Short and long transcripts use fixed 24- and 72-segment data sets.
- Populated utility states seed fixed learner, review, progress, explanation, and provider-settings data in IndexedDB.
- Loading and error states use deterministic language-model fixtures.
- Visual captures load the local `Pretendard Variable` asset instead of a CDN font.
