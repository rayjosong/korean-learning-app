# QA-18 - Simple learner profile

## Scope

Backlog #18 closes the existing learner-profile implementation from PR #44 and adds current regression evidence. The profile remains a local, derived read model; it does not add a new persisted profile table, AI-generated judgments, or a top-level navigation destination.

## Acceptance criteria evidence

| Criterion | Evidence |
| --- | --- |
| Known vocabulary summary | Aggregator counts saved known learner items; populated browser fixture asserts one known item even though its encounter count is five. |
| Learning vocabulary summary | Aggregator counts saved learning learner items; populated browser fixture asserts one learning item and refresh coverage asserts the count becomes two after saving another item. |
| Grammar item summary | Storage reads structured explanation grammar; domain tests cover whitespace normalization, case-insensitive deduplication, empty-label removal, and deterministic ordering. |
| Recognition confidence summary | Aggregator averages only saved known/learning items, clamps finite values to 0-100, treats invalid persisted values defensively, and returns null for empty input. |
| Production confidence summary | Production confidence is aggregated independently from recognition confidence and has the same bounded/empty contract. |
| Speech-level familiarity supported | Storage reads structured speech level; domain tests cover normalized exposure counts and deterministic exposed/familiar/well-exposed bands. The UI explicitly labels this as exposure, not mastery. |
