# QA-25 - Export learner data

## Scope

Backlog #25 adds a deterministic, local-only export of learner data. The export includes a versioned JSON format, learner items, history, review state, and explicitly excludes API provider settings credentials.

## Evidence

- Domain storage tests verify that the export retrieves all relevant Dexie tables successfully and shapes them into the required `LearnerDataExport` interface.
- Specific unit test ensures that `aiProviderSettings` are entirely excluded from the exported output, proving credentials remain secure on the local device.
- UI components `SettingsDashboard` and `LearnerDataExportPanel` handle exposing this action safely to the user as a button to download the JSON blob.
